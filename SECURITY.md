# Privacy and security

## Synthetic public data

All names, dates, places, biographies, and relationships in this repository are fictional. They were created specifically for the public showcase and are not derived from the private family database.

The repository excludes:

- The private SQLite database and WAL files
- Real family names, dates, places, notes, and source records
- Uploaded family photos
- Spreadsheets, certificates, and research documents
- Local IDE and runtime files

## Development guidance

Do not replace the fictional seed with real personal data in a public fork. Use an ignored local database and keep photos and source documents outside Git.

## Reporting

Use a private GitHub security advisory for vulnerabilities. Do not publish personal genealogical data in an issue.
